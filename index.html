    OTC Omega

    👤 Role: Senior Software Engineer     🏢 Company: EPAM Systems     🤝 Client: Procter & Gamble     📅 Duration: Dec 2025 - Present

    OTC Omega is an enterprise Order-to-Cash platform developed for Procter & Gamble to streamline sales order processing and operational workflows across multiple business functions and geographies. It centralizes sales order data, delivery-block management, planning cases, workbasket assignments, and issue resolution while integrating with SAP and other enterprise systems through an event-driven architecture.

    Key Features:

    • Centralized sales order, delivery-block, and issue management.
    • Automated planning case creation, prioritization, and workflow processing.
    • Rule-based workbasket assignment and user-scope management.
    • Event-driven integration with SAP, OTC Hub, and BluePrism.
    • GenAI-powered customer communication and email drafting.

    Tech Stack:

    Python, FastAPI, PostgreSQL, Microsoft SQL Server, SQLAlchemy, GenAI, REST APIs, SAP Integration, Azure Event Hub, Docker, Alembic, Pytest, Git, GitHub, GitHub Actions
